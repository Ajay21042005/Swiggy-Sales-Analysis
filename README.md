📊 Swiggy Sales Analysis Dashboard

📌 Project Overview

This project is an interactive Swiggy Sales Analysis Dashboard created using Microsoft Excel.

The purpose of this project is to analyze Swiggy's sales performance, customer ratings, order trends, food categories, cities, and geographical sales distribution.

The dashboard converts raw sales data into meaningful business insights using **Excel Pivot Tables, Pivot Charts, Slicers, KPIs, and Map Charts.

🎯 Project Objective

The main objective of this project is to analyze Swiggy sales data and answer important business questions such as:

- What is the total sales generated?
- What is the average order value?
- How many orders were placed?
- What is the average customer rating?
- Which cities generate the highest sales?
- Which months have higher sales?
- Which days generate higher sales?
- How do weekly sales change?
- What is the contribution of Veg and Non-Veg food?
- How are sales distributed across different states?
- How do ratings affect the analysis?
- How can interactive filters be used to analyze the data?
